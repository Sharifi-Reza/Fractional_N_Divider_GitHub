# Fractional-N Divider RTL & Gate-Level Verification

A four-week FPGA/ASIC-based system-design project implementing and verifying a
programmable Fractional-N clock divider. The final design supports integer divide modes
`N = 1, 2, 3`, safe dynamic ratio changes, an external divide-by-two T flip-flop, and
system-level integration with a MASH 1-1 sigma-delta modulator (SDM).

The repository emphasizes **verification engineering**: self-checking testbenches,
automated pass/fail scoring, timing/frequency measurement, continuous glitch detection,
watchdogs, RTL-to-gate correlation, and SDF-annotated post-synthesis simulation.

> **Project context:** developed as a four-person university course project. My principal
> contribution was the verification/testbench work, including substantial development of
> both final self-checking testbenches, regression execution, and RTL/post-synthesis
> validation. RTL development was collaborative; this repository does not claim sole
> authorship of the complete design.

## Highlights

- Self-checking Verilog/SystemVerilog verification for divider + external T-FF.
- Directed tests for reset, `N=1/2/3`, duty cycle, dynamic ratio changes, invalid controls,
  and long-term average frequency.
- Continuous runt/glitch monitor and missing-pulse watchdog.
- Reused the same verification intent at RTL and gate level with maximum-delay SDF.
- **13/13 direct checks passed** at both RTL and gate level.
- Long-term fractional-frequency test: **0.047701% error**, below the **0.1% requirement**.
- System-level `SDM -> divider -> T-FF` verification across 10 input/dither scenarios.
- **52/52 integration checks passed** in each of four RTL/post-synthesis configurations.
- Xcelium code-coverage flow included; the final archive does not contain an exported
  numerical IMC report, so no final coverage percentage is claimed here.

## Final Architecture

The input clock is nominally 131.072 kHz. A two-bit command selects the divider mode:

| `N_sel` | Active divide value | Output behavior |
|---|---:|---|
| `00` | 1 | `1 x T_RO`, 50% duty cycle |
| `01` | 2 | `2 x T_RO`, 1 cycle high / 1 cycle low |
| `10` | 3 | `3 x T_RO`, 1 cycle high / 2 cycles low |
| `11` | 2 | Safe fallback |

A new divide command is accepted only at a completed output-period boundary. The final
RTL generates the divider output from two edge-triggered state registers (`q_pos` and
`q_neg`) combined by XOR. This avoids a raw/generated-clock multiplexer in the final
implementation and prevents normal dynamic command changes from truncating an active
output pulse.

```text
                 +-------------------------+
RO_CLK --------->|  Fractional-N Divider   |------> INT65K_CLK
N_sel[1:0] ----->|      N = 1 / 2 / 3      |
reset_n -------->|                         |
                 +-------------------------+
                              |
                              v
                       +-------------+
                       | External TFF|
                       +-------------+
                              |
                              +--------------------> CLK32K
```

For system-level testing, `N_sel` is generated by a MASH 1-1 SDM:

```text
 epsilon_RO / dither
          |
          v
 +----------------+      N_sel      +---------------------+      +-----+
 | MASH 1-1 SDM   | --------------> | Fractional-N Divider| ---> | TFF | ---> CLK32K
 +----------------+                  +---------------------+      +-----+
                                             |
                                             +-------------------> INT65K_CLK
```

The SDM implementation used in the course integration originated from another team and
is intentionally **not redistributed** in this public portfolio package.

## Verification Strategy

### 1. Direct divider + T-FF testbench

`tb/tb_frac_div_system.v` is a self-checking testbench used for both RTL and gate-level
simulation. It contains:

- reusable PASS/FAIL check tasks;
- measured edge-to-edge period checks;
- duty-cycle measurements;
- asynchronous-reset verification;
- dynamic `N=2 -> N=3` and `N=2 -> N=1` transition tests;
- invalid-command (`2'b11`) fallback verification;
- long-term average-frequency measurement;
- continuous runt/glitch detection;
- missing-pulse watchdog logic;
- external T-FF frequency and duty-cycle checks.

The long-term test drives nine `N=2` periods followed by one `N=3` period, producing an
average command of `N = 2.1`.

### 2. SDM integration testbench

`tb/tb_system_g4.sv` verifies the complete `SDM -> divider -> T-FF` chain. Ten scenarios
are exercised:

1. Zero
2. +0.25
3. -0.25
4. Exact +50 ppm
5. Exact -50 ppm
6. Zero + dither
7. +0.25 + dither
8. -0.25 + dither
9. +50 ppm + dither
10. -50 ppm + dither

For each case, the testbench checks reset behavior, valid `N_sel` generation, generated
and applied average divide value, output-frequency agreement, and T-FF divide-by-two
behavior. Global monitors also check period-boundary command updates and runt pulses.

The original project ran the integration testbench in four configurations:

| SDM implementation | Divider implementation | Result |
|---|---|---:|
| RTL | RTL | **52 PASS / 0 FAIL** |
| Post-synthesis | RTL | **52 PASS / 0 FAIL** |
| RTL | Post-synthesis | **52 PASS / 0 FAIL** |
| Post-synthesis | Post-synthesis | **52 PASS / 0 FAIL** |

## Running the Public Divider Regression

### Requirements

- Cadence Xcelium (`xrun`) for the supplied simulation scripts.
- Bash shell.
- Cadence Genus only if you want to reproduce synthesis.
- An authorized local technology library for synthesis/gate-level simulation.

### RTL simulation

```bash
bash scripts/sim_xcelium_rtl.sh
```

A successful run finishes with:

```text
RESULT: PASS=13 FAIL=0
ALL WEEK-4 DIRECTED TESTS PASSED.
```

### Divider coverage run

```bash
bash scripts/sim_xcelium_coverage_divider.sh
```

The script runs Xcelium with `-coverage all` and writes the coverage database to
`cov_work/`. Open the database with Cadence IMC to inspect or export coverage reports.

### Synthesis

Do **not** commit a university or foundry technology library to GitHub. Point the script
to an authorized local installation instead:

```bash
export TSMC180_LIB_DIR=/path/to/authorized/TSMC180/lib
genus -f scripts/synth_genus_public.tcl
```

This generates local netlist/SDF/report artifacts that are excluded by `.gitignore`.

### Gate-level simulation

After locally generating the netlist and SDF, provide the technology Verilog model:

```bash
export TECH_V=/path/to/authorized/technology_model.v
bash scripts/sim_xcelium_gate_public.sh
```

## Coverage

The archived project includes Xcelium runs using `-coverage all`. Because the final
archive does not contain the numerical IMC export for the final implementation, this
repository deliberately avoids claiming a final coverage percentage. This is more
reproducible than carrying forward the 100% statement/branch figure from an earlier
architectural iteration.
